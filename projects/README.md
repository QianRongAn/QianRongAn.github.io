# Projects 动态概念 Demo

已接入主站 Projects 导航；也可独立打开预览。

打开 `index.html` 即可预览；也可以在此目录运行 `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。

- 默认显示两个项目名称，背景逐字复用网站幕帘的 45° DNA 螺旋动画脚本。
- 鼠标悬停项目时展开介绍和图片；移出后收起。
- 点击项目名称可固定展开，再次点击可收起；触屏设备使用点击。
- 图片可点击放大，按 Escape 或点击关闭按钮退出。
- 完整项目介绍位于可滚动文字区，没有删减用户提供的正文。
- MedLit 使用现有真实界面图片；Meta-ACDC 的图网络视觉为明确标注的概念示意，非实验结果。
- 系统开启“减少动态效果”时，DNA 背景和界面动效会静止。

文件均为普通 HTML、CSS、JS、SVG 和本地图片，不依赖外部接口或构建工具。
